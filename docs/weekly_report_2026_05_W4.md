**[결과]**

## 부록. 기술 용어 설명

| 용어 | 설명 |
| :--- | :--- |
| **Saga 패턴** | 여러 단계 작업 중 하나라도 실패하면 성공한 단계들을 역순으로 취소하는 분산 안전망 기법 |
| **보상 트랜잭션** | 이미 완료된 작업을 논리적으로 되돌리는 취소 명령 (예: 이미 발권된 항공권 취소 API 호출) |
| **고아 트랜잭션** | 외부에서 결제·예약은 완료됐는데 우리 시스템에 기록이 없는 데이터 불일치 상태 |
| **asyncio.gather** | 여러 비동기 작업을 동시에 병렬 실행하는 Python 함수 |
| **E2E 테스트** | 사용자 입력부터 최종 응답까지 전체 흐름을 하나로 검증하는 통합 테스트 방식 |
| **공수(MH)** | Man-Hour의 약자. 한 명이 한 시간 작업하는 단위 |
| **인터페이스 분리** | 외부에 공개하는 기능과 내부 구현을 명확히 나누어, 내부가 바뀌어도 외부 코드를 건드리지 않게 설계하는 방법 |
