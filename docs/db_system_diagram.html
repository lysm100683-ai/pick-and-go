1. 도형 규격 (ISO 5807 표준):
- 타원(시작/종료점), 직사각형(연산 기능), 마름모(조건 판단), 원통(DB/저장소), 평행사변형(사용자 입출력) 준수.
2. 동작의 입체적 가시화:
- [메인 스레드 - 실선 화살표]: 일정 생성을 멈추지 않고 신속하게 처리하기 위한 "초고속 캐시 메커니즘" 시각화.
- [백그라운드 스레드 - 점선 화살표]: 앱 응답 속도에 영향을 주지 않으면서(API 응답 이후) 방대한 데이터를 조용히 축적하는 전략 시각화.
